## Selected projects

### [AI Knowledge Copilot](https://github.com/Mansibaher/ai-knowledge-copilot)
**Ask questions about PDFs and trace answers back to their sources.**

Document Q&A using retrieval-augmented generation (RAG), with citations identifying the file, page, and retrieved passage. A FastAPI backend handles ingestion and retrieval; Streamlit provides the interface.

- **Engineering focus:** overlapping text chunks, semantic search, persisted chat history, and interchangeable LLM providers.
- **Design decision:** ChromaDB stores embeddings and document chunks; SQLite stores structured metadata and conversations.
- **Stack:** Python · FastAPI · Streamlit · ChromaDB · Sentence Transformers · SQLite · Docker

[Architecture, setup, and testing →](https://github.com/Mansibaher/ai-knowledge-copilot#readme)

### [Job Market Analytics](https://github.com/Mansibaher/Job-Market-Analytics)
**Explore skill demand in Data Analyst and ML Engineer job listings.**

An interactive dashboard using job listing data from SerpAPI to explore current hiring demand through charts.

- **Engineering focus:** connecting an external data source to an interactive analytics interface.
- **Stack:** Python · Streamlit · SerpAPI

[Dashboard link →](https://job-market-analytics-fvye3hzpsabbudvxymyrcf.streamlit.app/) · [Source →](https://github.com/Mansibaher/Job-Market-Analytics)

### [Book Club API](https://github.com/Mansibaher/BookClubAPI)
**Backend APIs for book clubs, book search, and discussions.**

A Kotlin/Ktor project with JWT authentication, Firebase integration, and Google Books search. Includes routes for club membership and discussion threads.

- **Engineering focus:** authenticated API access, external service integration, and structured responses.
- **Stack:** Kotlin · Ktor · Firebase Auth · Firestore · JWT · Gradle

[API endpoints and setup →](https://github.com/Mansibaher/BookClubAPI#readme)
